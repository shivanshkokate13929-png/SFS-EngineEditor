# SFS-EngineEditor

This Mod is for the game **Spaceflight Simulator (SFS)** (developed by Team Curiosity). It allows you to dynamically change the **Specific Impulse (Isp)** and **Thrust** of an engine component.

### 🔌 Compatibility
* **Supported Versions:** Spaceflight Simulator version **1.6.0.16 and above [for version 1.0.0]** 

### ⚠️ Known Limitations
* **Per-Engine Customization:** The mod can only edit one engine at a time as far as I have tested. Stat adjustments apply exclusively to the specific engine component you select. For instance, if you have two Hawk engines on the field and modify one, the second engine—as well as any new Hawk engines dragged from the part menu—will retain their original default stats.
* **Blueprint Screen Only:** Stat modifications can only be performed while inside the **Blueprint Editor** (the craft building screen). Changes cannot be made mid-flight.

## 🚀 Enjoy the Mod & Reporting Bugs
I hope you enjoy tweaking your rockets! If you encounter any issues, glitches, or unexpected behavior, please submit a bug report so I can improve future versions.
